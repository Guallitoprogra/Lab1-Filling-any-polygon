# Lab 1 - Filling any polygon

Laboratorio de graficas hecho en Zig.

El programa dibuja los cinco poligonos del enunciado y genera una imagen `out.png`. El quinto poligono se usa como agujero dentro del poligono grande, por eso no se rellena.

## Correr el programa

```powershell
zig build run
```

Al terminar se crea:

```text
out.png
```

No se debe subir `zig-out`, `.zig-cache` ni ejecutables compilados.
